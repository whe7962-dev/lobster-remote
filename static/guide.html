启动说明产品方案演示顺序验收记录

龙虾遥控台 · 面试 Demo · 2026-10-21

先从这里开始

这是一份能运行的本地 Demo。手机输入指令，Mac 或 Windows 执行。本次采用用户现有 Mac 真机联调；Windows 代码已提供，但没有 Windows 真机验收。录屏由你完成。

一、在你这台 Mac 上启动

  1. 打开交付文件夹 lobster-brain。保留里面的文件结构，不要只复制一个文件。
  2. 双击 启动Mac.command。电脑会出现一个启动窗口，并打开网页。保持启动窗口开启。当前电脑的依赖已准备好；新电脑首次运行需联网安装。
  3. 启动窗口中会出现“手机同一 Wi-Fi 打开”的地址，以及一个 6 位配对码。每次重启配对码会变化。
  4. 手机和电脑连接同一 Wi-Fi，在手机浏览器输入该地址。不要在手机输入 127.0.0.1，它在手机上代表手机自己。
  5. 输入配对码。页面顶部应显示“Mac 真机执行”和“执行端在线”。
  6. 点击“电影预告片”示例，再点击“发送给电脑”。也可修改书名号中的电影名。

电脑端地址：http://127.0.0.1:8765。手机地址以启动窗口显示为准，电脑换网络后可能变化。

二、会议首次授权

已登录腾讯会议客户端，并不等于自动创建工具已经授权。本次已完成官方工具授权；同一目录下继续使用通常无需再次授权。

  1. 新电脑或授权失效时，双击 授权腾讯会议.command。
  2. 在腾讯官网扫码登录，核对权限后，由你本人确认授权。该流程约 5 分钟超时，超时后重新运行脚本。
  3. 回到任务网页。若任务正在等待授权，点击“我已处理，重新检查”；否则提交“创建一个腾讯会议”。
  4. 成功后会返回真实会议号与邀请链接。创建的是从当前时间约 1 分钟后开始、持续 30 分钟的普通会议，主题为“龙虾遥控台 Demo + 任务编号”。
创建成功与进入会议是两种结果。本程序通过官方接口自动创建会议，并打开客户端供你查看。它不会自动接通麦克风或摄像头；不把打开客户端或人工入会记成自动入会成功。官方工具授权范围可能覆盖更多会议数据，使用结束可通过官方工具登出撤销本地凭据。

三、用这三句话验收

输入应该发生什么
搜索《流浪地球2》并播放预告片电脑打开浏览器搜索，选择标题匹配的视频；检测到视频时钟前进才显示自动完成。
创建一个腾讯会议电脑调用腾讯官方工具创建，返回真实会议号。可以在已登录客户端查看同一主题会议。
加入腾讯会议，会议码1234提示 9 位普通会议号／10 位个人会议号；不会执行错误入会操作。

“打开腾讯会议”也可执行。“加入有效会议号”目前是打开客户端并提示人工入会，不能把这条辅助流程说成自动加入。

四、遇到问题怎么处理

现象下一步
手机打不开网页确认电脑启动窗口还在运行；确认同一 Wi-Fi；使用窗口内的局域网地址。访客网络、VPN 或公司防火墙可能隔离设备；不要关闭全部防火墙，换可信家庭网络或允许此本地程序。
配对失败查看当前启动窗口的配对码。重启后旧码失效；连续输错 5 次需等待 1 分钟。
搜索或播放需要处理在电脑的任务浏览器中处理登录、验证码、缓冲或点击播放，再点“重新检查”。不要在其他浏览器窗口处理。
浏览器被关闭取消当前任务，重新提交。Mac 默认使用 Chrome，Windows 默认使用 Edge，需提前安装。
创建会议超时，结果未知先在客户端按任务提示的主题查询。程序不会自动再发创建请求，避免重复会议。核对后在电脑网页填写人工结果。
会议工具未授权运行授权脚本。确认网页授权的账号是你想用的账号；不要仅登录客户端。
已存在一个任务先处理或取消前一条任务，Demo 同时只允许一个活动任务。
启动窗口提示端口占用优先使用已经运行的窗口；关闭旧程序再启动，避免重复开多个副本。

五、Windows 启动方式（待真机验证）

  1. 安装 Python 3.10 或更高版本，保留 Python Launcher；确认 Microsoft Edge 已安装。
  2. 安装并登录腾讯会议，将整个交付包解压到一个普通文件夹。
  3. 双击 启动Windows.bat。首次启动会安装浏览器依赖。
  4. 双击 授权腾讯会议Windows.bat 完成独立授权。
  5. 根据启动窗口的地址和配对码连接手机，重复上面的三项验收。

如果腾讯会议不是默认安装路径，把 config.example.json 复制为 config.json，在 meeting_path 填入实际应用路径。Mac 填 .app 路径，Windows 填 wemeetapp.exe 路径。

六、交付与停止

  • 给面试官发送已打包的 ZIP；它不含你的授权凭据、浏览器登录状态和历史任务。
  • 不要直接发送本地工作文件夹里的 .local-auth、.venv 或 runtime。看板导出含任务指令和会议信息，分享前自行检查。
  • 停止服务：在启动窗口按 Control+C。已经创建的腾讯会议不会被自动删除；按需要在腾讯会议中结束或取消。
  • 仅预览页面时运行 预览Mac.command，页面会明确显示不执行桌面操作。

视频关闭与会议完整流程

  1. 创建：提交“创建一个腾讯会议”，官方接口返回真实会议号；创建成功不代表已入会。
  2. 入会：点击“打开此会议的入会入口”。这会打开该会议的客户端链接；依据客户端设置，可能直接进入，也可能需要你完成提示。请预先关闭入会麦克风和摄像头。网页依据官方会议状态及当前账号本机参会记录显示“已核验入会”，不以窗口打开作为成功证据。
  3. 结束：点击“结束会议（电脑确认）”，在电脑腾讯会议选择“结束会议”→“全员结束会议”。系统在约 3 分钟内定期查询官方状态；收到“已结束”才显示已结束。超过检查时间或查询失败，可点“检查会议状态”。仅离开会议、关闭窗口均不等于全员结束。
  4. 取消预约：“取消未开始的预约”仅用于本 Demo 创建、尚未进行的会议。进行中的会议会阻止取消，并提示使用结束流程。
  5. 关闭视频：在自然语言输入框输入“关闭”“关闭播放界面”或“关掉这个视频”，系统关闭本 Demo 最近一次执行的视频页面；不需要点击关闭按钮。结果卡保留关闭按钮作为备用入口。会议创建不会改变这条视频关闭指令的对象；没有视频时明确提示，重启后无法定位页面时提示待核对。

按用户选择，本版保留客户端人工入会、结束，不使用 AppleScript。当前授权的官方工具调用结束接口返回“该接口未开放”，因此没有自动结束承诺。客户端登录与官方工具授权相互独立，授权账号需与演示客户端账号一致；授权失效或官方接口不可用时如实提示，不能以人工口述代替官方核验。

数据看板分别统计自动关闭／取消、已核验入会、已核验结束和预约已取消。人工操作后的官方核验不计为自动结束成功；原创建成功率仅代表创建任务，不代表从创建到结束全自动完成。网页刷新加载更新；服务重启后使用新的配对码。
