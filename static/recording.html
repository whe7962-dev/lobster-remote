你来录屏：约 4 分钟演示顺序

本次按你的要求不代录视频。本页是录屏前的操作清单和口述提纲；演示必须显示真实电脑动作，不用预制动画替代。

录之前，先做一次不录屏的演练

  1. 双击启动脚本，手机同 Wi-Fi 配对。确认顶部显示 Mac 真机，执行端在线。
  2. 确认 Chrome 可访问 B 站；腾讯会议已登录，官方工具已完成独立授权。
  3. 提交一次电影任务与一次创建会议任务。播放器阻塞时先解决登录或验证码，不要等到正式录屏。
  4. 关闭无关个人窗口和通知。测试会议不邀请他人；麦克风与摄像头保持关闭。
  5. 安排画面：最好拍到手机输入与电脑执行，或并排展示手机录屏与电脑录屏。如果只展示电脑上窄屏网页，说明这是手机尺寸预览。

建议镜头与讲法

时间操作可直接使用的口述
0:00–0:20展示手机页面与 Mac这是龙虾遥控台最小 Demo。我用一句话让电脑执行两类明确任务。本次使用 Mac 真机，Windows 版本仍待验证。
0:20–1:10手机提交“搜索《流浪地球2》并播放预告片”，展示电脑搜索与播放，再看手机回执这里不是按固定时间显示成功。执行端读取了播放器的两次进度，确认视频正在播放，才把结果返回手机。
1:10–1:50提交“创建一个腾讯会议”，展示会议号与客户端中的同主题会议会议由电脑调用腾讯官方工具创建，返回真实会议号。创建和入会分开记录；本版不自动接通音视频。
1:50–2:15提交“加入腾讯会议，会议码1234”错误参数在执行前拦截，告诉用户缺少什么，而不是执行失败后只给一个红色提示。
2:15–2:40打开数据看板这些数字来自实际任务记录，自动完成、人工确认和校验失败分开计算。下一步根据失败原因决定优先修什么。
2:40–3:00展示产品方案与边界这个版本先证明可观察的执行闭环。下一步补 Windows 验收和恢复能力，再增加模型理解与跨网络设备连接。

如果现场失败

保留失败画面，说明原因与恢复方法。验证码或登录需要人工处理时，展示“需要你处理 → 重新检查”。不要剪掉关键人工步骤后声称全自动。创建结果未知时先查客户端，不重复点创建。

补录会议闭环（约 1 分钟）

创建返回会议号 → 点击入会入口 → 电脑完成入会 → 网页显示“已核验入会” → 点击“结束会议（电脑确认）” → 你在客户端选择“全员结束会议” → 网页显示“已结束”。保留真实等待，不能用剪辑把人工操作伪装成自动执行。口述：“创建自动执行；入会和结束保留人工控制，系统通过腾讯官方状态核验结果。”随后展示看板中分开的入会与结束统计。视频场景补录：播放成功后，在输入框输入“关闭”，展示电脑播放页关闭与网页真实关闭回执。

录完检查

  • 手机输入、电脑动作、真实反馈是否都出现？
  • 画面是否泄露配对码、个人资料、其他会议或登录二维码？分享视频前遮挡不必要的信息。
  • 有没有把“打开”“创建”和“入会”混为一谈？
  • 交付 ZIP 是否不含本地授权目录和浏览器会话？

视频关闭与会议完整流程

  1. 创建：提交“创建一个腾讯会议”，官方接口返回真实会议号；创建成功不代表已入会。
  2. 入会：点击“打开此会议的入会入口”。这会打开该会议的客户端链接；依据客户端设置，可能直接进入，也可能需要你完成提示。请预先关闭入会麦克风和摄像头。网页依据官方会议状态及当前账号本机参会记录显示“已核验入会”，不以窗口打开作为成功证据。
  3. 结束：点击“结束会议（电脑确认）”，在电脑腾讯会议选择“结束会议”→“全员结束会议”。系统在约 3 分钟内定期查询官方状态；收到“已结束”才显示已结束。超过检查时间或查询失败，可点“检查会议状态”。仅离开会议、关闭窗口均不等于全员结束。
  4. 取消预约：“取消未开始的预约”仅用于本 Demo 创建、尚未进行的会议。进行中的会议会阻止取消，并提示使用结束流程。
  5. 关闭视频：在自然语言输入框输入“关闭”“关闭播放界面”或“关掉这个视频”，系统关闭本 Demo 最近一次执行的视频页面；不需要点击关闭按钮。结果卡保留关闭按钮作为备用入口。会议创建不会改变这条视频关闭指令的对象；没有视频时明确提示，重启后无法定位页面时提示待核对。

按用户选择，本版保留客户端人工入会、结束，不使用 AppleScript。当前授权的官方工具调用结束接口返回“该接口未开放”，因此没有自动结束承诺。客户端登录与官方工具授权相互独立，授权账号需与演示客户端账号一致；授权失效或官方接口不可用时如实提示，不能以人工口述代替官方核验。

数据看板分别统计自动关闭／取消、已核验入会、已核验结束和预约已取消。人工操作后的官方核验不计为自动结束成功；原创建成功率仅代表创建任务，不代表从创建到结束全自动完成。网页刷新加载更新；服务重启后使用新的配对码。
