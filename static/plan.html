启动说明产品方案演示顺序验收记录

龙虾遥控台 · 面试 Demo · 2026-10-21

产品方案 · 把一句话变成电脑动作

目标用户：人在手机旁、任务却需要电脑完成的人。第一版只验证两个高频、结果可观察的动作：看一段指定电影相关视频，创建一场腾讯会议。

用户价值假设：降低在手机与电脑之间切换、找入口和填参数的成本。当前未做用户调研，不宣称已经验证市场需求；通过 Demo 验证交互可行性，再做小样本用户测试。

1. 本次范围与验收标准

场景交付行为成功依据
指定电影提取片名，搜索 B 站相关预告片，打开匹配结果并尝试播放同一视频元素的两次媒体时间读数前进，且处于播放状态；提供标题、链接和进度
创建会议本机调用腾讯官方 tmeet 创建普通会议，返回会议号并打开客户端官方创建响应含会议 ID 与会议号，并尝试只读查询核对
异常处理错误会议号、未授权、网络失败、播放器阻塞、执行取消显示实际原因与下一步；无证据时不报成功

明确不做：完整电影资源、实时热度排名、任意电脑任务、语音、多账号、多设备、公网远控、自动验证码处理。Windows 适配代码已提供，需真实 Windows 验证。本次采用用户指定的 Mac 真机方案。

2. 核心流程与体验边界

手机配对 → 输入一句话 → 参数校验 → 任务排队 → 本机执行 → 证据判断 → 结果回传。

需要登录、验证码、音视频授权或网络恢复时，进入“需要你处理”。电脑处理后可重新检查；用户报告与系统观测分别标为“人工确认完成”和“自动完成”。创建请求超时可能已经生效，此时结果标为未知，禁止盲目重试。

客户端打开、会议创建、成功入会是三个不同动作。当前自动完成的是创建；入会与媒体权限没有自动成功承诺。浏览器播放成功只证明相关视频正在播放，不证明整部电影、版权归属或内容质量。

3. 最小实现与 AI 的角色

一个本地 Python 服务提供手机网页、串行执行队列和 SQLite 记录。浏览器执行使用 Playwright；会议创建使用腾讯官方 CLI。手机每隔约 1.2 秒获取状态。同一 Wi-Fi 下演示，无需购买服务器。

AI 用于辅助编码、检查异常分支、生成文档与联调。运行时采用透明的有限意图规则，不冒充通用大模型推理。后续接入模型时，仍只允许输出经过校验的结构化动作，不允许直接运行模型生成的任意系统命令。

看板全部来源于本地真实记录，不注入模拟成功样本。下一轮建议招募 5 位目标用户，每人完成两类任务，记录独立完成率、人工干预次数及与手工操作相比的耗时；阈值在实测基线后制定。

5. 产品化路径

  1. 首先稳定：Windows 真机验收；处理不同版本播放器和腾讯会议权限；补网络中断、锁屏与重启恢复；支持任务证据截图并默认脱敏。
  2. 再提升理解：大模型提取意图、片名、会议时间；不确定参数先澄清；操作仍受允许列表和结构化校验约束。
  3. 最后扩展连接：设备身份、HTTPS、短期授权、权限分层、审计、跨网络连接与多设备调度。建立隐私保留期和删除入口后再扩大试用。

依据：腾讯官方 tmeet 项目；腾讯会议普通／个人会议号说明；Playwright 浏览器支持。

视频关闭与会议完整流程

  1. 创建：提交“创建一个腾讯会议”，官方接口返回真实会议号；创建成功不代表已入会。
  2. 入会：点击“打开此会议的入会入口”。这会打开该会议的客户端链接；依据客户端设置，可能直接进入，也可能需要你完成提示。请预先关闭入会麦克风和摄像头。网页依据官方会议状态及当前账号本机参会记录显示“已核验入会”，不以窗口打开作为成功证据。
  3. 结束：点击“结束会议（电脑确认）”，在电脑腾讯会议选择“结束会议”→“全员结束会议”。系统在约 3 分钟内定期查询官方状态；收到“已结束”才显示已结束。超过检查时间或查询失败，可点“检查会议状态”。仅离开会议、关闭窗口均不等于全员结束。
  4. 取消预约：“取消未开始的预约”仅用于本 Demo 创建、尚未进行的会议。进行中的会议会阻止取消，并提示使用结束流程。
  5. 关闭视频：在自然语言输入框输入“关闭”“关闭播放界面”或“关掉这个视频”，系统关闭本 Demo 最近一次执行的视频页面；不需要点击关闭按钮。结果卡保留关闭按钮作为备用入口。会议创建不会改变这条视频关闭指令的对象；没有视频时明确提示，重启后无法定位页面时提示待核对。

按用户选择，本版保留客户端人工入会、结束，不使用 AppleScript。当前授权的官方工具调用结束接口返回“该接口未开放”，因此没有自动结束承诺。客户端登录与官方工具授权相互独立，授权账号需与演示客户端账号一致；授权失效或官方接口不可用时如实提示，不能以人工口述代替官方核验。

数据看板分别统计自动关闭／取消、已核验入会、已核验结束和预约已取消。人工操作后的官方核验不计为自动结束成功；原创建成功率仅代表创建任务，不代表从创建到结束全自动完成。网页刷新加载更新；服务重启后使用新的配对码。
